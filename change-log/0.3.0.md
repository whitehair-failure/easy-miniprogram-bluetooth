## [0.3.0] - 2026-07-31

### 移除（破坏性变更）

**自定义错误体系（src/utils/error.ts）已删除**
- 移除 9 个自定义异常类：`BLEError`、`BLEAdapterError`、`BLEPermissionError`、`BLEConnectionError`、`BLETimeoutError`、`BLEDeviceNotFoundError`、`BLEServiceError`、`BLEConfigError`、`BLEIOError`
- 移除辅助函数：`formatError(err)`、`convertWxErrorToBLEError(err)`
- `index.ts` 不再导出 `./utils/error`

### 变更

- 所有模块中 catch 到微信原生错误的位置改为**直接 `throw err`**（保留原始 `errMsg` / `errno` / `errCode`），不再包装为自定义异常
- 参数校验 / 配置校验 / 超时场景改为抛出原生 `Error`（超时消息保留原文案，如"连接超时"、"写入响应超时 - 请求ID: xxx"）
- 受影响文件：`AdapterManager` / `DiscoveryManager` / `ConnectionManager` / `ServiceManager` / `IOManager` / `SingleDeviceBLEHandler` / `MultiDeviceBLEHandler`

### 迁移指引

调用方无法再通过 `instanceof BLEConnectionError` 等方式判断错误类型，需改为读取微信错误字段：

```typescript
catch (err) {
  if (err?.errno === 103 || err?.errCode === 103) { /* 权限未授权 */ }
  else if (err?.errMsg?.includes('timeout')) { /* 超时 */ }
}
```
