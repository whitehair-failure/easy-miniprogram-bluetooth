## [0.4.0] - 2026-08-27

### 新增

**调试日志开关**
- 新增 `src/utils/logger.ts`，统一日志工具：`setDebugEnabled` / `isDebugEnabled` / `debugLog` / `debugError` / `debugWarn`，默认静默
- `BLEHandlerConstructor` 新增 `debug?: boolean` 选项，构造时传入 `debug: true` 即可开启调试日志（仅显式传入时生效）
- 全库约 40 处 `console.*` 替换为统一日志工具，避免在宿主小程序中污染控制台

**配置校验工具**
- 新增 `src/utils/config.ts` 的 `validateBLEHandlerConfig`，`ServiceManager` 与 `IOManager` 共享复用，消除两处重复实现；补上 `IOManager` 构造器漏掉的配置校验

### 变更

- `notifyType` 支持运行时更新（`updateBLEHandlerConfig` 的允许键与赋值纳入 `notifyType`，校验枚举值）
- `updateBLEHandlerConfig` 改为遍历所有已连接设备重新订阅通知，多设备模式下全部生效
- `readCharacteristicValue` 返回类型由 `Promise<ArrayBuffer>` 改为 `Promise<number[]>`（新增 `CharacteristicValueResult` 类型），与全局监听器将 `ArrayBuffer` 转字节数组的逻辑一致
- `convertConfigUUIDs` 参数/返回类型收紧（`any` → `BLEHandlerConfig`）
- `validateCharacteristics` 特征值比对改为 UUID 大小写不敏感，并抽取 `hasCharacteristic` 消除三段重复
- `release()` 现在会清空设备列表与重连状态（`offDeviceFoundListener` / `offConnectionStateListener` 补齐重置）
- 错误信息统一为中文

### 修复

- **[严重] 构建产物与 package.json 入口脱节**：`rollup` 此前只产出 `dist/index.js`，而 `main` / `module` / `exports` 指向不存在的 `index.cjs.js` / `index.esm.js`。现同时产出 CJS 与 ESM 双产物并对齐入口
- **[严重] 类型声明缺失**：`dist/core/*.d.ts` 引用 `../types/ble` 但 `dist/types/ble.d.ts` 从未生成，发布后 TS 消费者会报 `Cannot find module '../types/ble'`。新增 `copyTypesPlugin` 把 `src/types/*.d.ts` 复制到 `dist/types/`
- 移除无效的 `rollup external: ["wx"]`（`wx` 为全局变量，非 `import`）
- `release()` 中假 API 名 `"offBLE* listeners"` 拆分为三个真实的 `off` API 判断
